## Oferta

- **Puesto:** Embedded Software Engineer
- **Responsabilidades:**
  - Design/implement firmware para embedded devices/systems, desde requirements a production/commercial deployment
  - Work closely con hardware y otros departamentos para design/build unit firmware y high-level satellite applications
  - Support definition de satellite/other systems architecture
  - Work on digital/analog embedded hardware
  - Prepare/maintain software detailed design/implementation documentation per company/industry standards
- **Requisitos obligatorios:**
  - Telecommunications/Electronics Engineering degree o similar
  - 3-5 años minimum related experience
  - Experience con C, C++, Python low-level programming languages
  - Familiarity con debugging embedded systems (STM32, Raspberry Pi, ESP32, etc.)
  - Basic understanding circuit schematics/layouts
  - Familiarity con communication protocols (CAN, I2C, SPI, UART, SPW, etc.)
  - Full professional proficiency en English
- **Deseables:**
  - Educational master level
  - Demonstrable interest in space sector
  - Experience developing embedded software in Linux environment
  - Experience working con digital HW (programmers, JTAG, oscilloscope, etc.)
  - Experience con real-time operating systems (preferiblemente FreeRTOS)
  - Strong skills optimizing/unit testing
  - Experience on Xilinx FPGAs
- **Condiciones:** Madrid (metropolitan area), Full Time, Indefinite contract, Flexible working arrangements, work-life balance focus
- **Encaje con el perfil:**
  - Firmware embebido C/C++/Python → CV
  - ESP32, STM32, Raspberry Pi → CV (ESP32-S3, ESP32-C6, Arduino, Raspberry Pi)
  - Linux embebido → CV (GNU/Linux, LXC, Kubernetes HA)
  - Protocolos CAN, I2C, SPI, UART, MQTT → CV (Zigbee, MQTT, protocolos serie)
  - FreeRTOS → Conocimientos base RTOS en formación (DAM + electricidad)
  - HW digital (JTAG, osciloscopio) → Formación eléctrica (cuadros, cableado, normativa, puesta en marcha)
  - Space sector interest → Diferenciador único (proyecto IoT extremo a extremo comparable)
  - Proyecto IoT extremo a extremo (ESP32 → Zigbee → MQTT → Node-RED → K8s HA) → Misma cadena dispositivo→cloud que buscan
  - **Qué no cubre:** 3-5 años experiencia relacionada específicamente space (tienes 20 años pero no en space); FPGA/Xilinx (no en CV); HW digital día a día (tienes base eléctrica pero no práctica diaria JTAG/osciloscopio); English full professional proficiency (CV: A2 sin certificado)
