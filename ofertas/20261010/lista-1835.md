### 1. Nextpower — Embedded Linux Software Engineer

- **Argumento:** Fabrica dispositivos de gestión de energía eléctrica con software en Linux y servicio web remoto para controlarlos: el mismo recorrido dispositivo → red → backend que cerró en Living Properties, y el único puesto de la lista donde sus 20 años leyendo la capa física (electricidad, cuadros, redes) son parte del producto y no un extra.
- **Qué cubre:** Linux a diario → mantenimiento y desarrollo de aplicaciones en Linux; backend y servicio web remoto → desarrollo de la API y el control remoto; Git/GitLab → flujo de control de versiones y revisiones de código; formación eléctrica FP2 → dominio del negocio (dispositivos de potencia).
- **Qué no cubre:** pide **inglés fluido** (CV: A2) — probable filtro duro; experiencia como desarrollador software formal (el CV acredita ~1 año embebido profesional más trayectoria de hardware); muy probable **C/C++ y kernel Linux** (CV: C básico). Publicada hace 1 día, entra por el margen de antigüedad.
- **Verificar antes de postular:** si el inglés es filtro de entrada; cuánto peso dan al conocimiento del dominio eléctrico frente a los años formales de software; idioma de la oferta: en.
- **Siguiente paso:** `nueva_candidatura.py "Nextpower"`

### 2. ISAGRI — Senior-Backend Developer

- **Argumento:** Empresa de producto (software para bodega, granja y facturación agrícola) con equipo 100 % remoto desde 2014 y contrato indefinido español; su stack —Python, Django, PostgreSQL, Kubernetes, Docker— es exactamente el backend cloud del CV, y el producto toca el mundo real (trazabilidad del litro, sensores de campo), donde la lectura física suma.
- **Qué cubre:** Python → backend Python; Kubernetes y Docker en producción → infraestructura y despliegue del puesto; APIs REST → integraciones; TDD y pair programming → forma de trabajo que ya practica con agentes de IA; español fluido → requisito cumplido.
- **Qué no cubre:** pide **>5 años de backend con un framework mayor (Django/RoR/Phoenix)**; el CV tiene Python sin Django profesional; **programación funcional** (Elixir/Phoenix); **buen inglés escrito** (CV: A2). Salario publicado: 45 k€ brutos/año.
- **Verificar antes de postular:** si el suelo de 5 años con framework es negociable dado el resto de la trayectoria; modalidad remota real desde Valencia.
- **Siguiente paso:** `nueva_candidatura.py "ISAGRI"`

### 3. URBIOTICA — Backend Software Engineer

- **Argumento:** Empresa de producto IoT puro (100.000 sensores de smart parking desplegados): el departamento gestiona datos que llegan de sensores y cámaras reales y su `servicio` es el mismo eje del CV —capa física + backend + cloud— tecnología por tecnología (Python y Java, Kubernetes, PostgreSQL, Flutter, IA-first con Claude Code/Copilot).
- **Qué cubre:** Python y Java del CV → backend en ambos lenguajes (modernizar el Java existente); Kubernetes/Docker/AWS → despliegue del puesto; PostgreSQL → datos; Flutter → la app móvil de su stack; sensores y hardware real → dominio IoT del CV; uso diario de asistentes de IA → «AI-first tooling» que anuncian.
- **Qué no cubre:** pide **3–4+ años de backend profesional** (el CV tiene ~1 año formal); **inglés** de trabajo en equipo multicultural (A2); la oferta es **50 % remoto con sede en Barcelona** (habría que ver presencia mínima); entra el campo `Streaming` (Flink) y `Computer Vision`, fuera del CV.
- **Verificar antes de postular:** política de presencialidad real en Barcelona; si valoran el perfil firmware/IoT aunque el backend formal sea corto.
- **Siguiente paso:** `nueva_candidatura.py "URBIOTICA"`

### 4. EM&E Group (DAS Photonics) — Ingeniero de firmware

- **Argumento:** Fotónica de defensa y espacio en Valencia: firmware que se valida sobre hardware real, con responsabilidad técnica sobre todo el ciclo de vida; el perfil —electricidad, ESP32, protocolos de bus, impresión 3D— es el de quien ya cierra el circuito entre el esquema electrónico y el código, algo directamente aplicable a drivers/periféricos.
- **Qué cubre:** ESP32/Arduino y depuración de periféricos → drivers y comunicación entre dispositivos (UART/SPI/I2C); lectura de esquemas y puesta en marcha eléctrica → apoyo directo al hardware; Git y documentación técnica → trazabilidad de requisitos; oferta recién publicada (4 días) e idioma español.
- **Qué no cubre:** **imprescindible 3 años de firmware profesional** en industria/aeronáutica/espacio/defensa (el CV tiene ~1 año embebido); **C/C++ avanzado** y ARM/STM32 (CV: C/C++ básico); **RTOS** (FreeRTOS/Zephyr/VxWorks); depuración con JTAG/SWD/osciloscopio en entorno profesional; inglés técnico.
- **Verificar antes de postular:** si el requisito de 3 años es absoluto o valoran la trayectoria eléctrica; si el inglés es solo para documentación (más alcanzable que el de Nextpower).
- **Siguiente paso:** `nueva_candidatura.py "EM&E Group"`
